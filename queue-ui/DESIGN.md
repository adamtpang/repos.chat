# Companions and chapters

The local repos.chat interface is a visit from one repo pet. Its source report leads to three possible next prompts, with a custom direction always available. Picking a path opens an editable draft. Exact-text approval and the existing relay remain the delivery boundary.

Palette: sky #eaf2ff, paper #ffffff, ink #182d52, blue #2959d9, line #d2def0, peach #ffd3a9. Trebuchet MS gives headings and controls a friendly, compact voice; Aptos and sans-serif are fallbacks. No external font dependencies.

The signature is the folder creature: repository-shaped ears, curious eyes, small feet. Stable variations distinguish companions without implying runtime capabilities. A narrow roster sits beside a spacious, left-aligned chapter; on mobile it becomes a horizontal companion selector. Progress is a short source excerpt, with full text, provenance, and receipts disclosed on demand.

Three paths: continue the recorded recommendation, verify the last result, or reconsider the route. These are deterministic suggestions grounded in imported context, not fresh advice generated by another agent. Blocked projects receive an input-seeking first path. Running, pending, parked, and unknown tasks allow exploring paths but retain existing delivery guards.

Keep public examples fictional. This interface and all real project content remain local.
