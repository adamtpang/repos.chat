# Companion adventure

Learned from Pacifica's adventure design: short beats, three distinct choices, free direction, and continuity. repos.chat keeps its own blue/folder-pet identity. No Pacifica fictional canon is copied.

Play shows a source-based recap and three editable paths. Keys 1/2/3 select a path outside editable or interactive controls. Choosing is not sending. Copy the prompt for the original Codex/Claude task, or explicitly queue it for the existing Codex relay. The session-owning bridge stays opt-in and is currently disabled.

Map groups companions by recorded state, without inventing geography, relationships or progress. Journal combines source reports, saved backend drafts, approved requests, and this browser's unsent drafts. Source reports are not independently verified completion claims. There is no XP for sending prompts.

Browser-local continuity stores the selected pet, view, and unfinished prompts. Approval authority is never restored from browser storage. Drafts can be discarded. The server's existing durable journal remains authoritative for requests and observations.

Private prepared scenes live in .repo-connect/adventure-scenes.json, bound to the source revision and exact source result. A changed source invalidates the prepared scene. These are authored interpretations of saved context, not live agent activity; generated structured results remain supported. All text is rendered as text, never as model-provided markup. New reports need refreshed scene preparation to maintain context-specific choices; the current fallback is still limited.

Validation: 33 tests pass. Helium verified keyboard selection, switching views, restoring the Journal tab and exact edited prompt after reload, discarding a draft, and 390px mobile layout. No project prompt was dispatched during implementation.
